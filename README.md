# Quarries of road-construction materials: Uzbekistan

A static web page that maps the quarries of the national road-construction
materials register and calculates haul distances from a quarry to a road
section. Open it at https://jamshidsod.github.io/quarry-platform/

This repository holds only the published page. It is generated from the
register; do not edit files here by hand.

Roads and background map © OpenStreetMap contributors (ODbL). Region
boundaries are open data (geoBoundaries) and are not official. The map
library is Leaflet 1.9.4 (BSD-2-Clause, see `vendor/leaflet/LICENSE`).
